# Atelier Pratique – OpenAI Codex (Décembre 2025)

## Objectif de l’atelier
Découvrir et expérimenter **OpenAI Codex** en tant qu’agent IA autonome pour le développement logiciel,  
et comprendre son impact sur la productivité et le rôle du développeur.

---

## Correction de bugs avec Codex

### Objectif
Utiliser Codex pour identifier et corriger un bug dans une application existante.

### Activité
- Fournir un petit projet (ex : application Todo ou API simple)
- Lancer la tâche :
  > *"Fix this bug and explain the solution"*
- Observer le code corrigé proposé par Codex

### Résultat attendu
- Bug corrigé
- Explication claire du problème et de la solution

---

## Ajout de fonctionnalité

### Objectif
Tester la capacité de Codex à ajouter une nouvelle fonctionnalité complète.

### Activité
- Projet de base (blog, gestion d’utilisateurs, CRUD simple)
- Demande à Codex :
  > *"Add an authentication feature (login/logout)"*
- Analyse du code généré

### Résultat attendu
- Nouvelle fonctionnalité fonctionnelle
- Structure du code cohérente

---

## Refactorisation de code

### Objectif
Améliorer la qualité et la lisibilité d’un code existant.

### Activité
- Fournir un code volontairement mal structuré
- Demande à Codex :
  > *"Refactor this code to improve readability and performance"*

### Résultat attendu
- Code plus clair
- Meilleure organisation des fonctions et fichiers

---

## Codex vs Développeur humain

### Objectif
Comparer la performance de Codex avec celle d’un développeur.

### Activité
- Donner la même tâche à un étudiant et à Codex
- Comparer :
  - Temps de réalisation
  - Qualité du code
  - Clarté des explications

### Résultat attendu
- Analyse comparative
- Discussion sur les forces et limites de Codex

---

## Prompt Engineering avec Codex

### Objectif
Comprendre l’importance de la formulation des prompts.

### Activité
- Même tâche, plusieurs prompts différents
- Exemple :
  - Prompt simple
  - Prompt détaillé
  - Prompt avec contraintes (performance, sécurité)

### Résultat attendu
- Résultats différents selon le prompt
- Compréhension de l’impact du prompt engineering

---

## Conclusion de l’atelier
Cet atelier montre que **OpenAI Codex** est un outil puissant pour assister le développeur,  
mais qu’il nécessite toujours une **validation humaine**.  
Codex agit comme un accélérateur de développement plutôt qu’un remplaçant du développeur.
